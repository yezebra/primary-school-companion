# primary-school-companion

给陪伴型 AI / 桌宠用的**小学生放学后互动进度策略**。

它解决的问题：一个设定成“四年级小学生”的 AI，晚上跟你聊“今天学校学了什么”，不该背课文目录，也不该反问你“你们讲到哪了”。它应该像一个真的小学生：有年级、有教材、有进度、有记不清的时候。

## 它包含什么

| 部分 | 内容 |
|---|---|
| 课程数据 | 人教版 1~6 年级，语文 / 数学 / 英语，上下册单元表 |
| 进度算法 | 按开学日和周次，把单元摊到周；支持手动覆盖 |
| 人设模板 | 人物宪章结构：我是谁、我知道什么、我怎么说话、我的学校记忆 |
| 晚间话术 | 17:30 主动聊“今天学了什么”的提示词模板 |
| 城市映射 | 主要城市 → 教材版本、开学时间（可扩展） |

## 快速开始

```bash
python3 src/progress.py --grade 4 --city 武汉 --date 2026-10-26
```

输出这一周各科大概在学什么，以及一段可以直接喂给模型的话术提示。

## 设计原则

- **进度是“记忆”，不是“表格”**：给模型的是“上周五语文讲女娲补天，老师让编小神话”，不是“第 8 周 第 4 单元”。
- **允许误差**：同一版本不同学校能差 2~3 周，数据里标了 `weeks_flex`，话术要求模型说“可能记混了”。
- **角色优先**：先有人物宪章，再谈课程；没有宪章，课程数据只会让它更像复读机。
- **数据可替换**：所有教材数据是 JSON，换版本不用改代码。

## 目录

```
data/renjiao/chinese.json   人教版语文 1~6 年级
data/renjiao/math.json      人教版数学
data/renjiao/english.json   人教版英语（PEP，多数学校 3 年级起）
data/cities.json            城市 → 教材 / 开学日
src/progress.py             进度计算与话术生成
prompts/character.md        人物宪章模板
prompts/evening.md          晚间主动聊天的提示词
docs/DATA.md                数据来源、误差与扩展说明
examples/                   示例输出
```

## 数据准确性

单元表来自公开教材目录，按常见教学进度摊到 20 周；**不是官方教学计划**。学校实际进度可能差 1~3 周，请以 `weeks_flex` 和话术里的模糊表达兜底。
